🌸 Rose Laser Center — Landing Page & Booking App
A bilingual (Kurdish Sorani / Arabic), RTL-first, single-file landing page and appointment booking app for Rose Laser Center in Erbil, Iraq.

The entire application lives in a single index.html file using Tailwind CSS (via CDN), Font Awesome icons, and the Noto Kufi Arabic font — no build step required.

✨ Features
🎨 Design
Rose / rose-gold aesthetic with soft gradients, glassmorphism cards, and glow shadows

Floating petal animation in the background (pure CSS keyframes)

Fully RTL layout optimized for Kurdish (Sorani) and Arabic

Mobile-first, max-width container designed to feel like a mobile app on desktop

Sticky glass header with logo, title, and language switcher

🌐 Bilingual (Kurdish ⇄ Arabic)
One-tap language toggle (کوردی ⇄ العربية) in the header

Every visible string, option, label, placeholder, and confirmation message is translated

Date formatting localized via Intl.DateTimeFormat (ku-Arab-IQ / ar-IQ)

Time formatting switches between PM and م for Arabic

Selected language applies consistently across the form and the generated WhatsApp/SMS message

📄 Two-Page Flow
Landing page — hero, gold offer, 3 key advantages, location & contact card, CTA

Booking form — name, phone, service, date, time

Smooth fade/slide transitions between pages

Auto-scroll to top on navigation

📅 Booking Form
Pre-filled date (today) with min set to today (no past dates)

Time slots from 2:00 PM to 9:00 PM in 30-minute increments

Six service options, including the "Full Body + free second session" offer

HTML5 validation (required fields)

📲 Booking Confirmation
On submit, a modal appears showing a summary of the booking and two send options:

WhatsApp — opens wa.me with a pre-filled message

SMS — opens the native SMS app with the same pre-filled message
The message includes name, phone, service, date, and time in the currently selected language.

🚀 Usage
No installation, no build tools. Just open the file:

bash
# Option 1 — double-click index.html

# Option 2 — serve locally (recommended for testing on phone)
npx serve .
# or
python -m http.server 8000
Then visit http://localhost:8000.

Note: Because the app relies on CDN assets (Tailwind, Font Awesome, Google Fonts), an internet connection is required on first load.

🛠️ Customization
Change the phone number
Search for 9647508315115 (used in both the WhatsApp and SMS links) and the display number 0750-831-5115 in the contact card.

Change the address
Edit the locVal translation key in both ckb and ar blocks:

js
locVal: "هەولێر - بەختیاری",     // Kurdish
locVal: "أربيل - بختياري",       // Arabic
Add / edit services
Edit the <option> elements in #selectService, then update the matching opt1–optN keys in the translations object for both languages.

Change available time slots
Add or remove <option> values in #inputTime (format: "H:MM PM"). Arabic labels are auto-generated by updateTimeLanguage().

Change colors
All brand colors are defined in the tailwind.config block inside <head>:

rosepink — primary pink scale

rosegold — secondary muted-rose scale

Edit all text
Every user-facing string lives in the translations object:

js
const translations = {
  ckb: { /* Kurdish Sorani */ },
  ar:  { /* Arabic */ }
};
Update both languages to keep the switch in sync.

Petal animation
Tune the count / size / speed in createPetals():

js
for (let i = 0; i < 15; i++) { ... }
Set the count to 0 to disable petals entirely.

✅ Browser Support
Works on all modern browsers (Chrome, Edge, Firefox, Safari). Uses backdrop-filter for the glass effect — gracefully degrades to a semi-transparent solid in older browsers.

📌 Known Notes / Limitations
No backend. Bookings are not stored — they are sent by the user via WhatsApp or SMS. If you need server-side storage, you'll need to add an API endpoint in handleFormSubmit().

No form persistence. Refreshing the page resets the form.

CDN dependency. For fully offline use, vendor Tailwind, Font Awesome, and the font locally.

Phone number is hard-coded in two places (WhatsApp + SMS links) plus the display card — update all three if it changes.
